

## Introduction

In the previous chapter, we learned different retrieval techniques.

Even with a good Retriever,

the retrieved documents are not always perfect.

Sometimes:

- Important documents are missing.
- Irrelevant documents are retrieved.
- The user's question is poorly written.
- The Retriever misunderstands the query.

Fortunately,

there are several techniques that improve retrieval quality.

The three most common are:

- Re-ranking
- Query Rewriting
- Multi-Query Retrieval

---

# 13.1 Why Do We Need Better Retrieval?

Imagine the user asks:

```text
How many vacation days do employees receive?
```

The Retriever returns:

```text
Document 1
Office Timings
```

```text
Document 2
Leave Policy
```

```text
Document 3
Company History
```

Notice that:

- Leave Policy is correct.
- Office Timings is only partially related.
- Company History is irrelevant.

Can we improve the ranking?

Yes.

---

# 13.2 Re-ranking

The Retriever quickly finds documents.

But speed is its priority.

It doesn't always rank them perfectly.

A **Re-ranker** reviews the retrieved documents again and rearranges them.

Instead of:

```text
Office Timings
Leave Policy
Company History
```

It changes them to:

```text
Leave Policy
Office Timings
Company History
```

The LLM now receives better context.

---

# 13.3 How Re-ranking Works

```text
User Question
      │
      ▼
Retriever
      │
      ▼
Top 10 Documents
      │
      ▼
Re-ranker
      │
      ▼
Best 3 Documents
      │
      ▼
LLM
```

Notice something.

The Re-ranker does **not** search the database.

It only improves the order of the retrieved documents.

---

# 13.4 Why Is Re-ranking Useful?

Suppose two documents are retrieved.

Document A

```text
Employees receive paid leave.
```

Document B

```text
Employees receive 24 paid leave days every year.
```

Both are relevant.

But Document B is clearly better.

The Re-ranker moves it to the top.

---

# 13.5 Query Rewriting

Sometimes the problem is not the documents.

The problem is the user's question.

Example

```text
Vacation?
```

This question is too short.

A Query Rewriter changes it into:

```text
How many paid leave days do employees receive?
```

Now retrieval becomes much more accurate.

---

# 13.6 Another Example

User writes:

```text
Laptop
```

The system rewrites it as:

```text
What is the company's laptop replacement policy?
```

The rewritten query contains more context.

---

# 13.7 Multi-Query Retrieval

Sometimes,

one question can be asked in many different ways.

Example

```text
How many vacation days do employees receive?
```

The system automatically creates multiple versions.

```text
How many paid leave days are allowed?
```

```text
What is the employee leave policy?
```

```text
How much annual leave is provided?
```

Each query searches the Vector Database.

The results are combined.

This increases the chance of finding the best documents.

---

# 13.8 Why Multi-Query Helps

Suppose the document says:

```text
Annual Leave
```

The user asks:

```text
Vacation Days
```

The Retriever may miss it.

But one rewritten query contains:

```text
Annual Leave
```

Now the correct document is retrieved.

Install:

```bash
pip install langchain
```

Example

```python
from langchain.retrievers.multi_query import MultiQueryRetriever

multi_query = MultiQueryRetriever.from_llm(
    retriever=retriever,
    llm=llm
)

documents = multi_query.invoke(
    "How many vacation days do employees receive?"
)
```

LangChain automatically generates multiple search queries.

# Common Beginner Mistakes

### Mistake 1

Thinking Re-ranking searches the database.

It doesn't.

It only rearranges retrieved documents.

---

### Mistake 2

Thinking Query Rewriting changes the user's intent.

It shouldn't.

It should only make the query clearer.

---

### Mistake 3

Thinking Multi-Query Retrieval asks the user multiple questions.

It doesn't.

The system automatically generates alternative search queries internally.

---

# Key Takeaways

- Re-ranking improves the order of retrieved documents.
- Query Rewriting makes unclear questions easier to search.
- Multi-Query Retrieval searches using multiple versions of the same question.
- These techniques improve retrieval quality before information reaches the LLM.
- Better retrieval usually leads to better RAG responses.
