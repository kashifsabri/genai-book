# Step 7 — Backpropagation

The model has now calculated the loss.

Suppose the model predicted:

```text
London
```

But the correct answer was:

```text
Paris
```

The model now knows:

> **"I made a mistake."**

But one important question remains.

> **How can the model avoid making the same mistake again?**

The answer is **Backpropagation**.

---

# 1.45 What is Backpropagation?

Backpropagation is the process of sending the error **back through the neural network**.

Its job is to find:

- Which weights caused the mistake?
- Which weights should be changed?
- How much should each weight change?

Think of it as the model learning from its mistakes.

---

# 1.46 A Simple Example

Imagine you're learning basketball.

You throw the ball.

Unfortunately, you miss the basket.

Your coach says:

```text
You threw the ball too far.

Next time, use less force.
```

What happens?

You change your throw slightly.

Then you try again.

If you keep practicing,

your shots become more accurate.

Backpropagation works in exactly the same way.

The model makes a prediction.

If it's wrong,

it receives feedback and adjusts itself.

---

# 1.47 Where Does the Error Go?

Remember our Transformer.

```text
Input
   │
   ▼
Embedding Layer
   │
   ▼
Transformer Block 1
   │
   ▼
Transformer Block 2
   │
   ▼
Transformer Block 3
   │
   ▼
Prediction
```

After calculating the loss,

the error travels in the **opposite direction**.

```text
Prediction
   │
   ▲
Transformer Block 3
   │
   ▲
Transformer Block 2
   │
   ▲
Transformer Block 1
   │
   ▲
Embedding Layer
```

This is why it is called **Backpropagation**.

The error moves **backward** through the network.

---

# 1.48 What Does Backpropagation Change?

During backpropagation,

the model **does not change the architecture**.

It only changes the **weights**.

Remember,

the weights contain everything the model has learned.

Examples:

- Grammar
- Word relationships
- Facts
- Programming patterns

By changing the weights,

the model gradually becomes more accurate.

---

# 1.49 Does Every Weight Change?

Yes.

Modern LLMs contain **billions of weights**.

During backpropagation,

every trainable weight is checked.

Some weights change a lot.

Some weights change only a little.

The goal is always the same:

> **Reduce the loss.**

---

# 1.50 Is Backpropagation Done Once?

No.

Suppose the model reads one sentence.

```text
Sentence

↓

Prediction

↓

Loss

↓

Backpropagation
```

Now it reads another sentence.

The same process happens again.

Then another sentence.

Again.

Again.

Again.

This process repeats **billions of times** during training.

Every repetition helps the model improve.

---

# 1.51 Real-World Example

Imagine learning to ride a bicycle.

The first time,

you may lose balance.

You adjust your posture.

You try again.

You improve a little.

After hundreds of attempts,

riding becomes natural.

The model learns in exactly the same way.

It improves one small step at a time.

---

# Engineering Note

Backpropagation is one of the most computationally expensive parts of training.

It requires storing additional information from the forward pass and computing gradients for every trainable parameter.

This is one reason why **training** requires much more memory and compute than **inference**.

---

Something else performs that job.
