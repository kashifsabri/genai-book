# 2. Pretraining & Next Token Prediction

## Introduction

Before a model can answer questions, write code, or generate stories, it must first learn how language works.

This first learning stage is called **Pretraining**.

During pretraining, the model reads an enormous amount of text and gradually learns patterns in language.

It is important to understand that:

> **The model is not taught facts directly.**

Instead, it learns by solving one simple task over and over again.

> **Predict the next token.**

This simple task is powerful enough to teach the model grammar, reasoning, coding patterns, writing styles, and many other language skills.

---

# 2.1 What is Pretraining?

Pretraining is the **first stage** of training a Large Language Model.

The goal is to teach the model a general understanding of language.

At this stage, the model is not trained for one specific task.

It is simply learning from large amounts of text.

For example,

the model reads:

- Books
- Wikipedia
- Research papers
- Programming code
- Technical documentation
- Public websites

By reading this data, the model begins to understand how language is structured.

---

# 2.2 Why is it Called "Pretraining"?

The word **pretraining** means:

> **Training before the real application.**

Think of a medical student.

First,

they spend years learning general medicine.

Later,

they become specialists.

For example,

- Heart Surgeon
- Neurologist
- Pediatrician

Pretraining works the same way.

First,

the model learns general language.

Later,

it can be fine-tuned for specific tasks.

---

# 2.3 What Does the Model Learn During Pretraining?

The model learns many different patterns.

Examples include:

- Grammar
- Sentence structure
- Word relationships
- Writing styles
- Programming syntax
- Mathematics
- General knowledge found in the training data

Notice something important.

The model is **not memorizing a textbook**.

It is learning statistical patterns from a very large amount of text.

---

# 2.4 Next Token Prediction

Every training example asks the same question.

Suppose the sentence is:

```text
The Earth revolves around the
```

The correct next token is:

```text
Sun
```

The model predicts a token.

If it predicts correctly,

the loss is small.

If it predicts incorrectly,

the loss is large.

Then the weights are updated.

This process repeats billions of times.

---

# 2.5 Another Example

Input:

```text
Roses are red,
Violets are
```

Correct next token:

```text
blue
```

The model tries to predict:

```text
blue
```

If it predicts:

```text
green
```

the prediction is wrong.

The optimizer updates the model so it performs better next time.

---

# 2.6 Why Does Next Token Prediction Work?

At first,

predicting the next token seems like a simple task.

But to predict the next token correctly,

the model must understand:

- Grammar
- Meaning
- Context
- Word relationships

Consider this sentence.

```text
The bank approved my loan.
```

To predict the next token,

the model needs to understand that:

```text
bank
```

means a financial institution.

Now look at this sentence.

```text
The children sat near the river bank.
```

Now,

the same word has a different meaning.

To predict correctly,

the model must understand the surrounding context.

This is why Next Token Prediction teaches the model much more than simply completing sentences.

---

# 2.7 Does the Model Read One Sentence at a Time?

No.

Modern GPUs process many examples together.

Example:

```text
Sentence 1

Sentence 2

Sentence 3

Sentence 4
```

These are grouped into a **batch**.

Processing batches makes training much faster.

---

# 2.8 When Does Pretraining Stop?

Pretraining continues until the model has processed an enormous number of tokens.

For large models,

this may be:

- Hundreds of billions of tokens
- Trillions of tokens

Once pretraining is complete,

the model becomes a **Foundation Model**.

Examples include:

- GPT
- Llama
- Mistral
- Qwen

These models already understand language reasonably well.

---

# 2.9 Foundation Model

A **Foundation Model** is a model that has completed pretraining.

It has learned general language patterns.

However,

it is not yet optimized for chatting with users or following instructions.

Additional training stages are often applied before the model is released.

We'll study those stages in later chapters.

---

# 2.10 Real-World Example

Imagine learning English.

First,

you read thousands of books.

You learn:

- Vocabulary
- Grammar
- Sentence structure

Later,

you learn a specific skill,

such as writing business emails.

Pretraining is like learning the language.

Fine-tuning is like learning a specific profession.

---

# Engineering Note

Pretraining is usually the most expensive stage of building an LLM.

It may require:

- Thousands of GPUs
- Weeks or months of training
- Massive amounts of electricity
- Trillions of training tokens

This is why only a few organizations train foundation models from scratch.

Most companies start with an existing pretrained model and fine-tune it for their own applications.

---

# Common Beginner Mistakes

### Mistake 1

Thinking the model is taught every answer by humans.

It isn't.

The model teaches itself by predicting the next token.

---

### Mistake 2

Thinking pretraining is the final stage.

It isn't.

Many models go through additional stages such as instruction tuning and alignment.

---

### Mistake 3

Thinking Next Token Prediction is too simple to create an intelligent model.

Although the task is simple,

repeating it billions of times allows the model to learn surprisingly complex language patterns.

---

# Key Takeaways

- Pretraining is the first stage of training an LLM.
- During pretraining, the model learns from massive amounts of text.
- The main training objective is Next Token Prediction.
- The model improves through repeated prediction, loss calculation, backpropagation, and weight updates.
- After pretraining, the model becomes a Foundation Model that can later be fine-tuned for specific tasks.
