#  Step 6 — Predict the Next Token and Calculate the Loss

The forward pass has finished.

The model has predicted the next token.

Now we compare the prediction with the **actual correct token**.

This comparison tells us how well the model performed.

---

# 1.37 Next Token Prediction

Remember,

an LLM is trained to solve one simple task:

> **Predict the next token.**

Example:

Input

```text
The capital of France is
```

Correct next token

```text
Paris
```

Suppose the model predicts:

```text
London
```

The prediction is wrong.

Now the model needs to measure **how wrong** it was.

---

# 1.38 The Model Predicts Probabilities

The model doesn't directly output a word.

Instead, it predicts a probability for **every token** in its vocabulary.

Example:

| Token | Probability |
|--------|------------:|
| Paris | 0.20 |
| London | 0.55 |
| Rome | 0.15 |
| Berlin | 0.10 |

The model chooses:

```text
London
```

because it has the highest probability.

Unfortunately,

the correct answer is:

```text
Paris
```

The model made a mistake.

---

# 1.39 What is Loss?

**Loss** is simply a number that tells us:

> **How wrong was the model's prediction?**

If the prediction is very close to the correct answer,

the loss is **small**.

Example:

```text
Loss = 0.08
```

If the prediction is completely wrong,

the loss becomes much larger.

Example:

```text
Loss = 4.91
```

So,

```text
Small Loss

↓

Good Prediction
```

```text
Large Loss

↓

Poor Prediction
```

The goal of training is simple:

> **Reduce the loss as much as possible.**

---

# 1.40 How is Loss Calculated?

Large Language Models usually use a loss function called:

```text
Cross Entropy Loss
```

Don't worry about the mathematics.

Think of it as a scoring system.

If the model predicts the correct token,

it receives a good score.

If it predicts the wrong token,

it receives a poor score.

The loss function converts this into a number.

---

# 1.41 Example

Suppose the correct sentence is:

```text
I love AI
```

The model predicts:

```text
I love Football
```

Since the prediction is wrong,

the loss becomes large.

Now consider another prediction.

```text
I love Artificial Intelligence
```

This prediction is much closer.

So the loss becomes much smaller.

Better predictions produce smaller loss values.

---

# 1.42 Why is Loss Important?

Imagine you're learning to play cricket.

After every shot,

your coach tells you:

```text
Good Shot
```

or

```text
Wrong Timing
```

Without feedback,

you wouldn't know how to improve.

The loss function is the model's coach.

It tells the model how well it performed.

---

# 1.43 Real-World Example

Imagine throwing a dart at a target.

If the dart lands near the center,

your mistake is very small.

If it lands far away,

your mistake is much larger.

The loss works in the same way.

It measures how far the model's prediction is from the correct answer.

---

# Engineering Note

During training,

the model predicts **every next token** in every sentence.

The loss is calculated for all these predictions.

The average of these losses is then used to improve the model.

This is why training an LLM involves billions of loss calculations.
