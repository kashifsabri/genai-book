# 13. Inference Engines

## Introduction

Training an LLM is only one part of the journey.

After a model is trained, it needs software that can load it, manage memory, process user requests, and generate responses.

This software is called an **Inference Engine**.

Think of it like this.

The LLM is the **engine of a car**.

The inference engine is everything that makes the engine usable, including starting it, managing resources, and controlling how it runs.

Without an inference engine, using a large language model would be difficult.

---

# 13.1 What is an Inference Engine?

An inference engine is software that runs a trained LLM.

Its responsibilities include:

- Loading the model
- Loading the tokenizer
- Managing GPU or CPU memory
- Processing prompts
- Generating tokens
- Returning the final response

Example:

```text
User Prompt
      │
      ▼
Inference Engine
      │
      ▼
LLM
      │
      ▼
Generated Response
```

The user interacts with the inference engine, not directly with the model.

---

# 13.2 Why Do We Need an Inference Engine?

Imagine you download an open-source Llama model.

Can you simply double-click it and start chatting?

No.

The model is just a collection of weights.

Something must:

- Load those weights
- Convert text into tokens
- Run the Transformer
- Generate tokens one by one
- Convert tokens back into text

That "something" is the inference engine.

---

# 13.3 Popular Inference Engines

Some popular inference engines are:

- vLLM
- Ollama
- llama.cpp
- Hugging Face Transformers
- Text Generation Inference (TGI)

Each one is designed for different use cases.

---

# 13.4 Hugging Face Transformers

The simplest way to run an LLM is with the Transformers library.

Example:

```python
from transformers import AutoTokenizer
from transformers import AutoModelForCausalLM

tokenizer = AutoTokenizer.from_pretrained("gpt2")
model = AutoModelForCausalLM.from_pretrained("gpt2")
```

Generate text.

```python
inputs = tokenizer(
    "Explain AI",
    return_tensors="pt"
)

output = model.generate(
    **inputs,
    max_new_tokens=50
)

print(tokenizer.decode(output[0]))
```

This is excellent for learning and experimentation.

---

# 13.5 Ollama

Ollama is one of the easiest ways to run open-source LLMs locally.

Example:

Install a model.

```bash
ollama pull llama3
```

Run it.

```bash
ollama run llama3
```

Now you can chat with the model directly from your computer.

Ollama is popular because it is:

- Easy to install
- Beginner friendly
- Supports many open-source models

---

# 13.6 llama.cpp

llama.cpp is an inference engine designed to run LLMs efficiently on CPUs and consumer hardware.

It is commonly used with:

- GGUF models

Its advantages include:

- Runs on laptops
- Low memory usage
- Fast CPU inference

---

# 13.7 vLLM

vLLM is designed for **high-performance GPU inference**.

It is commonly used in production systems.

Some of its features include:

- High throughput
- Efficient KV Cache management
- Faster serving of multiple user requests

Many companies use vLLM to serve LLMs through APIs.

---

# 13.8 Text Generation Inference (TGI)

TGI is an inference server developed by Hugging Face.

It is designed for deploying LLMs in production.

Features include:

- REST API
- Token streaming
- Multi-user support
- GPU optimization

It is commonly used when deploying LLMs on servers.

---

# 13.9 Which One Should You Use?

| Tool | Best For |
|------|----------|
| Transformers | Learning and development |
| Ollama | Running models locally |
| llama.cpp | CPU inference |
| vLLM | Production GPU serving |
| TGI | Production APIs |

# Common Beginner Mistakes

### Mistake 1

Thinking the model and the inference engine are the same.

They are different.

The model contains the learned knowledge.

The inference engine runs the model.

---

### Mistake 2

Thinking Ollama trains models.

It doesn't.

It only runs pretrained models.

---

### Mistake 3

Thinking vLLM makes the model smarter.

It doesn't.

It makes inference faster and more efficient.

---

# Key Takeaways

- An inference engine runs a trained LLM.
- It handles model loading, tokenization, generation, and memory management.
- Transformers is ideal for learning.
- Ollama is great for local inference.
- llama.cpp is optimized for CPUs.
- vLLM and TGI are designed for production deployments.
