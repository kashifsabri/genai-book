#  Step 1 — Collect Massive Text Data

The first step in training an LLM is collecting a huge amount of text.

Remember,

an LLM learns by reading examples.

The more high-quality text it reads, the better it can learn patterns in language.

Unlike humans, an LLM doesn't read hundreds of books.

It reads the equivalent of **millions of books**.

The training data usually comes from many different sources.

Examples include:

- Books
- Research papers
- Wikipedia
- News articles
- Public websites
- Programming code
- Technical documentation
- Question-and-answer websites
- Public conversations and forums
- Government publications

Every source teaches the model something different.

For example,

Books help the model learn:

- Grammar
- Storytelling
- Writing styles

Programming repositories help it learn:

- Python
- Java
- C++
- JavaScript
- SQL

Research papers help it understand technical concepts.

Wikipedia helps it learn general knowledge.

By combining all these sources, the model develops a broad understanding of language.

---

# 1.6 Why Use Different Types of Data?

Imagine learning only from mathematics books.

You would become good at mathematics.

But you might struggle with:

- Writing emails
- Holding conversations
- Explaining history
- Writing stories

Now imagine learning from:

- Books
- Newspapers
- Websites
- Scientific articles
- Programming tutorials

You would become much more knowledgeable.

LLMs learn in the same way.

Different types of text help the model become useful across many tasks.

---

# 1.7 Is All Internet Data Used?

No.

This is a common misunderstanding.

Companies do **not** simply copy the entire internet into an LLM.

The collected data goes through several filtering and cleaning steps before training.

Some examples of content that may be removed include:

- Duplicate text
- Spam
- Corrupted files
- Low-quality webpages
- Machine-generated junk
- Broken documents

The goal is to train the model using **high-quality text**.

A smaller, cleaner dataset is often better than a much larger, noisy one.

---

# 1.8 How Much Data Is Needed?

Modern LLMs are trained on enormous datasets.

Instead of counting documents, researchers usually measure the size in **tokens**.

Large models may be trained on:

- Hundreds of billions of tokens
- Trillions of tokens

Remember,

a token is not always a complete word.

It may be:

- A word
- Part of a word
- A punctuation mark
- A special symbol

We'll learn more about tokens in the next chapter.

---

# 1.9 Real-World Example

Imagine you're preparing for the world's toughest exam.

Would you study from only one textbook?

Probably not.

You would study from:

- Books
- Notes
- Research papers
- Previous exam questions
- Online tutorials

The more high-quality material you study, the better prepared you become.

An LLM learns in exactly the same way.

Instead of reading one source, it learns from many different sources.

---

# Engineering Note

Collecting data is only the beginning.

Most of the effort in training an LLM is **not** the neural network itself.

A significant amount of engineering work goes into:

- Collecting data
- Cleaning data
- Removing duplicates
- Filtering harmful or low-quality content
- Preparing the data for training

High-quality data is one of the biggest reasons why modern LLMs perform so well.
