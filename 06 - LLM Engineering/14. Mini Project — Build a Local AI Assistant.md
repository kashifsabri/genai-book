# Step 1 — Load the Model

```python
from transformers import AutoTokenizer
from transformers import AutoModelForCausalLM

model_name = "gpt2"

tokenizer = AutoTokenizer.from_pretrained(model_name)

model = AutoModelForCausalLM.from_pretrained(model_name)
```

---

# Step 2 — Accept User Input

```python
prompt = input("You: ")
```

---

# Step 3 — Tokenize the Prompt

```python
inputs = tokenizer(
    prompt,
    return_tensors="pt"
)
```

---

# Step 4 — Generate a Response

```python
output = model.generate(
    **inputs,
    max_new_tokens=100
)
```

---

# Step 5 — Convert Tokens Back to Text

```python
response = tokenizer.decode(
    output[0],
    skip_special_tokens=True
)

print(response)
```

---

# Step 6 — Create a Chat Loop

```python
while True:

    prompt = input("You: ")

    if prompt.lower() == "exit":
        break

    inputs = tokenizer(
        prompt,
        return_tensors="pt"
    )

    output = model.generate(
        **inputs,
        max_new_tokens=100
    )

    response = tokenizer.decode(
        output[0],
        skip_special_tokens=True
    )

    print("\nAssistant:")
    print(response)
```

Now your assistant can answer multiple questions.
