# 6. PEFT, LoRA & QLoRA

## Introduction

Modern Large Language Models contain **billions of parameters**.

For example:

- Llama 3 8B → 8 Billion parameters
- Llama 3 70B → 70 Billion parameters

Training or fine-tuning all these parameters requires:

- Large GPUs
- A lot of memory
- High training cost
- Long training time

This is not practical for most developers.

Instead of updating the entire model, we can update only a very small part of it.

This idea is called **Parameter-Efficient Fine-Tuning (PEFT).**

PEFT includes techniques such as:

- LoRA
- QLoRA
- Adapters
- Prefix Tuning

Among these, **LoRA** and **QLoRA** are the most widely used.

---

# 6.1 What is PEFT?

PEFT stands for:

**Parameter-Efficient Fine-Tuning**

Instead of updating billions of parameters,

PEFT updates only a small number of trainable parameters.

Think of it like this.

Instead of rebuilding an entire house,

you only renovate one room.

This saves:

- Memory
- Time
- Compute
- Cost

---

# 6.2 Why Do We Need PEFT?

Suppose you want to fine-tune an 8-billion-parameter model.

Without PEFT:

```text
Update all 8 Billion parameters
```

With PEFT:

```text
Update only a few million parameters
```

The result is much cheaper and much faster.

---

# 6.3 What is LoRA?

LoRA stands for:

**Low-Rank Adaptation**

Instead of changing the original model weights,

LoRA adds **small trainable matrices** to certain layers.

During training:

- Original model weights stay frozen.
- Only the LoRA matrices are updated.

After training,

the model learns the new task without modifying the original weights.

---

# 6.4 How LoRA Works

Normal Fine-Tuning

```text
Input
   │
   ▼
LLM
(All weights updated)
```

LoRA Fine-Tuning

```text
Input
   │
   ▼
Frozen LLM
   │
   ▼
Small LoRA Layers
(Only these are updated)
```

This dramatically reduces memory usage.

---

# 6.5 Why Freeze the Original Model?

Imagine you have an expensive textbook.

Instead of writing directly in the book,

you write notes on sticky notes.

The original book remains unchanged.

The sticky notes contain your new knowledge.

LoRA works in the same way.

The original model stays unchanged.

Only the LoRA layers learn.

---

# 6.6 Python Example (LoRA)

Install the required libraries.

```bash
pip install peft transformers
```

Load a model.

```python
from transformers import AutoModelForCausalLM

model = AutoModelForCausalLM.from_pretrained(
    "gpt2"
)
```

Create a LoRA configuration.

```python
from peft import LoraConfig

config = LoraConfig(
    r=8,
    lora_alpha=32,
    target_modules=["c_attn"],
    lora_dropout=0.1
)
```

Attach LoRA to the model.

```python
from peft import get_peft_model

model = get_peft_model(model, config)
```

Now only the LoRA layers are trainable.

---

# 6.7 What is QLoRA?

QLoRA stands for:

**Quantized Low-Rank Adaptation**

It combines two ideas:

- Quantization
- LoRA

The original model is first stored in a compressed format.

Then LoRA layers are trained on top of it.

This reduces memory usage even further.

---

# 6.8 Why is QLoRA Popular?

Suppose a model normally needs:

```text
32 GB GPU Memory
```

After quantization,

it may require much less memory.

Now LoRA trains only a small number of parameters.

This allows developers to fine-tune large models on a single GPU that would otherwise be too small.

---

# 6.9 LoRA vs QLoRA

| LoRA | QLoRA |
|------|--------|
| Original model stays in full precision | Original model is quantized |
| Lower memory than full fine-tuning | Even lower memory |
| Faster than full fine-tuning | More memory efficient |
| Very popular | Extremely popular for large LLMs |

---

# 6.10 Real-World Example

Imagine editing a large PDF.

Instead of creating a completely new PDF,

you create a small file containing only the changes.

Whenever someone opens the PDF,

those changes are applied.

LoRA works in a similar way.

The original model remains unchanged.

Only a small set of learned changes is stored.

---

# Common Beginner Mistakes

### Mistake 1

Thinking LoRA trains the entire model.

It doesn't.

Only the LoRA layers are updated.

---

### Mistake 2

Thinking LoRA creates a new model from scratch.

It builds on an existing pretrained model.

---

### Mistake 3

Thinking QLoRA and Quantization are the same.

They are different.

QLoRA uses quantization to reduce memory and LoRA to perform efficient fine-tuning.

---

# Key Takeaways

- PEFT stands for Parameter-Efficient Fine-Tuning.
- LoRA updates only a small number of trainable parameters.
- The original model weights remain frozen.
- QLoRA combines quantization with LoRA.
- LoRA and QLoRA make fine-tuning large language models much cheaper and more accessible.
