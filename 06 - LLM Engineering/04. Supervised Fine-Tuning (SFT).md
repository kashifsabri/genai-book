# 4. Supervised Fine-Tuning (SFT)

## Introduction

In the previous chapter, we learned that a pretrained model has a lot of knowledge, but it doesn't know how to behave like a helpful AI assistant.

For example, if you ask it to:

- Translate a sentence
- Summarize an article
- Explain a concept
- Write an email

it may not give the answer you expect.

To solve this problem, the model goes through another training stage called **Supervised Fine-Tuning (SFT)**.

SFT teaches the model **how to follow instructions**.

---

# 4.1 What is Supervised Fine-Tuning?

Supervised Fine-Tuning (SFT) is the process of training a pretrained model using **instruction-answer pairs**.

Each training example contains:

- An instruction (input)
- The correct response (output)

Example:

```text
Instruction

Translate "Hello" to French.
```

```text
Answer

Bonjour
```

The model learns that when it sees this instruction, it should generate the correct answer.

---

# 4.2 Why is it Called "Supervised"?

The word **Supervised** means the model is given the correct answer during training.

Imagine a teacher asking a student:

```text
Question:

What is 5 + 5?
```

The teacher already knows the correct answer.

```text
Answer:

10
```

The student compares their answer with the correct one and learns from the mistake.

SFT works in the same way.

The model always has the correct response available during training.

---

# 4.3 What Does an SFT Dataset Look Like?

An SFT dataset contains thousands or millions of examples.

Example 1

```text
Instruction

What is Machine Learning?
```

```text
Answer

Machine Learning is a field of Artificial Intelligence where computers learn patterns from data.
```

---

Example 2

```text
Instruction

Write a Python program to add two numbers.
```

```text
Answer

a = 10
b = 20

print(a + b)
```

---

Example 3

```text
Instruction

Summarize this article.
```

```text
Answer

The article explains the importance of renewable energy.
```

The model learns from every instruction-answer pair.

---

# 4.4 What Happens During SFT?

The process is very similar to pretraining.

```text
Instruction
      │
      ▼
Tokenizer
      │
      ▼
Transformer
      │
      ▼
Generate Response
      │
      ▼
Compare with Correct Answer
      │
      ▼
Calculate Loss
      │
      ▼
Backpropagation
      │
      ▼
Update Weights
```

The only difference is that the model is now learning from **instructions**, not random internet text.

---

# 4.5 Example

Suppose the training example is:

```text
Instruction

Explain gravity in simple words.
```

The ideal answer is:

```text
Gravity is the force that pulls objects toward the Earth.
```

Suppose the model generates:

```text
Gravity is a planet.
```

This is incorrect.

The loss becomes large.

The optimizer updates the weights.

Next time, the model is more likely to produce the correct explanation.

---

# 4.6 What Does the Model Learn?

During SFT, the model learns many useful behaviors.

For example:

- Following instructions
- Answering questions
- Explaining concepts
- Writing emails
- Generating code
- Summarizing documents
- Translating languages

Notice that the model is **not learning a new language**.

It is learning **how to respond correctly to user requests**.

---

# 4.7 Does SFT Add New Knowledge?

Not usually.

Most of the knowledge was already learned during pretraining.

SFT mainly teaches the model:

- How to use that knowledge
- How to organize answers
- How to follow instructions
- How to respond in a helpful way

Think of it like this:

```text
Pretraining

↓

Learns knowledge
```

```text
SFT

↓

Learns behavior
```

---

# 4.8 Real-World Example

Imagine a new employee joining a company.

The employee already knows programming.

But every company has its own way of working.

The company teaches the employee:

- How to write reports
- How to communicate with customers
- How to follow company guidelines

The employee gains new working habits without relearning programming.

SFT works in exactly the same way.

---

# 4.9 Is SFT Enough?

SFT makes the model much better.

But there is still a problem.

Sometimes the model may:

- Give unsafe answers
- Produce biased responses
- Be overly confident
- Generate harmful content

To improve the model further, another training stage is used.

This stage is called **RLHF (Reinforcement Learning from Human Feedback)**.

We'll study it in the next chapter.

---

# Common Beginner Mistakes

### Mistake 1

Thinking SFT trains a model from scratch.

It doesn't.

It starts with a pretrained model.

---

### Mistake 2

Thinking SFT teaches the model all its knowledge.

Most knowledge comes from pretraining.

SFT mainly teaches instruction-following.

---

### Mistake 3

Thinking every company performs pretraining.

Most companies use an existing foundation model and perform only SFT on their own data.

---

# Key Takeaways

- Supervised Fine-Tuning (SFT) comes after pretraining.
- SFT uses instruction-answer pairs.
- The model learns how to follow user instructions.
- The training process still uses loss, backpropagation, and weight updates.
- SFT improves the model's behavior, not its general language knowledge.
- After SFT, many models go through another stage called RLHF.
