# 8. Decoding Strategies

## Introduction

In the previous chapter, we learned that an LLM predicts the probability of every token in its vocabulary.

For example,

| Token | Probability |
|--------|------------:|
| Paris | 0.82 |
| London | 0.10 |
| Rome | 0.05 |
| Berlin | 0.03 |

Now a question arises.

> **Which token should the model choose?**

Should it always choose the token with the highest probability?

Or should it sometimes choose another token to generate more creative text?

The method used to select the next token is called a **Decoding Strategy**.

Different decoding strategies produce different outputs.

---

# 8.1 Why Do We Need Decoding Strategies?

Suppose you ask:

```text
Write a story about a dragon.
```

If the model always picks the most likely word,

every generated story may become very similar.

Sometimes we want:

- Creative stories
- Different responses
- More natural conversations

This is why different decoding strategies exist.

---

# 8.2 Greedy Decoding

Greedy Decoding is the simplest strategy.

The model always selects the token with the **highest probability**.

Example:

| Token | Probability |
|--------|------------:|
| Paris | 0.82 |
| London | 0.10 |
| Rome | 0.05 |

The model chooses:

```text
Paris
```

because it has the highest probability.

This happens at every generation step.

---

## Advantages

- Fast
- Simple
- Deterministic

---

## Disadvantages

- Can produce repetitive text
- Less creative
- May miss better sentences

---

# Python Example

```python
output = model.generate(
    **inputs,
    do_sample=False
)
```

Setting:

```python
do_sample=False
```

uses Greedy Decoding.

---

# 8.3 Temperature

Temperature controls how random the model becomes.

Think of it as a creativity control.

Low temperature:

```text
More predictable
```

High temperature:

```text
More creative
```

Example:

```python
temperature=0.2
```

The model becomes conservative.

Example output:

```text
Artificial Intelligence is a branch of computer science.
```

Now try:

```python
temperature=1.2
```

Possible output:

```text
Artificial Intelligence is opening new possibilities across science, art, education, and countless other fields.
```

The response becomes more varied.

---

# Python Example

```python
output = model.generate(
    **inputs,
    do_sample=True,
    temperature=0.8
)
```

---

# 8.4 Top-K Sampling

Instead of considering every token,

the model only looks at the **top K most likely tokens**.

Suppose the vocabulary contains 50,000 tokens.

With:

```python
top_k=50
```

the model ignores the other 49,950 tokens.

Example:

Without Top-K

```text
Paris

London

Rome

Berlin

Apple

Dog

Coffee

...
```

With:

```python
top_k=3
```

Only these are considered.

```text
Paris

London

Rome
```

The next token is selected from these three.

---

# Python Example

```python
output = model.generate(
    **inputs,
    do_sample=True,
    top_k=50
)
```

---

# 8.5 Top-P (Nucleus Sampling)

Top-K always keeps a fixed number of tokens.

Top-P works differently.

Instead of keeping a fixed number,

it keeps enough tokens whose combined probability reaches a limit.

Example:

```python
top_p=0.9
```

The model keeps selecting tokens until their total probability reaches **90%**.

This makes generation more flexible.

---

# Python Example

```python
output = model.generate(
    **inputs,
    do_sample=True,
    top_p=0.9
)
```

---

# 8.6 Beam Search

Beam Search does not keep only one sentence.

Instead,

it keeps multiple possible sentences at the same time.

Example:

Prompt:

```text
The capital of France is
```

The model explores multiple possibilities.

```text
Beam 1

↓

Paris
```

```text
Beam 2

↓

London
```

```text
Beam 3

↓

Berlin
```

After several steps,

the model chooses the sentence with the highest overall score.

Beam Search is often used in:

- Machine Translation
- Text Summarization

It is less common for chatbot-style conversations because responses can become less natural.

---

# Python Example

```python
output = model.generate(
    **inputs,
    num_beams=5
)
```

---

# 8.7 Repetition Penalty

Sometimes an LLM repeats the same words.

Example:

```text
AI is very very very very very important.
```

A repetition penalty reduces this problem.

Example:

```python
repetition_penalty=1.2
```

The model becomes less likely to repeat the same words.

---

# Python Example

```python
output = model.generate(
    **inputs,
    repetition_penalty=1.2
)
```

---

# 8.8 Combining Parameters

In real applications,

multiple decoding parameters are used together.

Example:

```python
output = model.generate(
    **inputs,
    max_new_tokens=100,
    do_sample=True,
    temperature=0.7,
    top_k=50,
    top_p=0.9,
    repetition_penalty=1.1
)
```

This is a common configuration for chat applications.

---

# 8.9 Which Strategy Should You Use?

| Use Case | Recommended Strategy |
|----------|----------------------|
| Factual answers | Greedy Decoding |
| Chatbots | Temperature + Top-P |
| Story generation | Temperature + Top-K + Top-P |
| Translation | Beam Search |
| Summarization | Beam Search |

There is no single best strategy.

The choice depends on the application.

---

# Real-World Example

Imagine you're writing an email.

One approach is to always choose the first word that comes to mind.

This is like **Greedy Decoding**.

Another approach is to think of several possible words before choosing the best one.

This is similar to **Beam Search**.

If you're writing a creative story,

you might choose less common words to make the story more interesting.

This is similar to using **Temperature** and **Top-P**.

---

# Common Beginner Mistakes

### Mistake 1

Thinking Temperature changes the model's knowledge.

It doesn't.

It only changes how tokens are selected.

---

### Mistake 2

Thinking Beam Search is always better.

It works well for tasks like translation but is not always the best choice for chatbots.

---

### Mistake 3

Using a very high temperature for factual questions.

High temperature increases creativity but may reduce accuracy.

---

# Key Takeaways

- Decoding strategies decide how the next token is selected.
- Greedy Decoding always picks the highest-probability token.
- Temperature controls randomness.
- Top-K limits the selection to the K most likely tokens.
- Top-P selects tokens based on cumulative probability.
- Beam Search explores multiple candidate sequences before choosing the best one.
- Repetition Penalty helps reduce repeated words or phrases.
- Different applications use different decoding strategies.
