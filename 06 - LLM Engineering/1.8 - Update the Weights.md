#  Step 8 — Update the Weights

Backpropagation has finished.

The model now knows:

- Which weights caused the mistake.
- Which weights should change.
- How much they should change.

But nothing has actually changed yet.

The job of updating the weights is done by an **Optimizer**.

---

# 1.53 What is an Optimizer?

An **Optimizer** is an algorithm that updates the model's weights.

Its goal is simple.

> **Change the weights so the model makes fewer mistakes in the future.**

Think of the optimizer as the model's teacher.

Backpropagation identifies the mistakes.

The optimizer corrects them.

---

# 1.54 How Does It Work?

Suppose the model predicts:

```text
The capital of France is

↓

London
```

The correct answer is:

```text
Paris
```

The loss becomes large.

Backpropagation calculates how the weights should change.

The optimizer then updates those weights.

Next time the model sees a similar sentence,

it is more likely to predict:

```text
Paris
```

instead of

```text
London
```

---

# 1.55 Learning Happens Little by Little

The optimizer **does not completely rewrite the model** after one mistake.

Instead,

it makes **very small changes**.

Think of it like adjusting a steering wheel while driving.

You don't suddenly turn the wheel all the way.

You make small corrections.

The optimizer works the same way.

After millions or billions of small updates,

the model gradually becomes much more accurate.

---

# 1.56 Learning Rate

How big should each update be?

This is controlled by something called the **Learning Rate**.

A learning rate decides **how much the weights change after each update**.

Imagine climbing down a mountain.

If you take steps that are too large,

you might fall.

If you take steps that are too small,

it will take a very long time to reach the bottom.

The learning rate works in the same way.

```text
Very Large Learning Rate

↓

Fast updates

↓

May become unstable
```

```text
Very Small Learning Rate

↓

Slow updates

↓

Training takes much longer
```

The goal is to choose a balanced learning rate.

---

# 1.57 Common Optimizers

There are many optimizers.

Some popular ones are:

- SGD (Stochastic Gradient Descent)
- Adam
- AdamW

Modern LLMs commonly use **AdamW** because it performs well for large Transformer models.

Don't worry about the mathematical details.

The important idea is that all optimizers try to improve the model by updating its weights.

---

# 1.58 One Complete Learning Cycle

Let's put everything together.

```text
Input Sentence
        │
        ▼
Tokenization
        │
        ▼
Embeddings
        │
        ▼
Forward Pass
        │
        ▼
Prediction
        │
        ▼
Loss Calculation
        │
        ▼
Backpropagation
        │
        ▼
Optimizer Updates Weights
```

This is **one training step**.

The same process is repeated over and over again.

---

# 1.59 How Many Times Does This Happen?

Not ten times.

Not a thousand times.

Not even a million times.

Modern LLMs repeat this learning cycle **billions of times**.

Every batch of training data follows the same process.

Over time,

the model becomes better at predicting the next token.

---

# 1.60 Real-World Example

Imagine learning to play the piano.

You play a song.

Your teacher points out mistakes.

You practice again.

You improve a little.

After thousands of practice sessions,

you become a skilled pianist.

Training an LLM works the same way.

The model improves through continuous practice and small corrections.

# Engineering Note

Training does **not** stop after one pass through the dataset.

The model usually reads the dataset multiple times.

Each complete pass through the dataset is called an **Epoch**.

For very large language models, training is often measured in **tokens processed** rather than epochs because the datasets are extremely large.

# Common Beginner Mistakes

### Mistake 1

Thinking backpropagation updates the weights.

It doesn't.

Backpropagation calculates how the weights should change.

The optimizer performs the actual update.

---

### Mistake 2

Thinking the model learns everything after one update.

It doesn't.

Learning happens through billions of small updates.

---

### Mistake 3

Thinking every weight changes by the same amount.

Each weight is updated differently depending on how much it contributed to the error.

# Key Takeaways

- The optimizer updates the model's weights after backpropagation.
- Learning happens through many small weight updates.
- The learning rate controls the size of each update.
- AdamW is one of the most common optimizers used for modern LLMs.
- One complete training step consists of a forward pass, loss calculation, backpropagation, and weight update.
- This cycle is repeated billions of times to train a Large Language Model.
