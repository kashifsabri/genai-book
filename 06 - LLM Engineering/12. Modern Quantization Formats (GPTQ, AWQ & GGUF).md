# 12. Modern Quantization Formats (GPTQ, AWQ & GGUF)

## Introduction

In the previous chapter, we learned different quantization techniques like PTQ and QAT.

Now let's look at some popular quantization methods used in the LLM ecosystem.

If you've downloaded open-source models from Hugging Face, you've probably seen names like:

- GPTQ
- AWQ
- GGUF

These are different ways of storing or quantizing a model.

Each one is designed for different use cases.

---

# 12.1 GPTQ

GPTQ stands for:

**Generative Pre-trained Transformer Quantization**

GPTQ is a **Post-Training Quantization (PTQ)** method.

This means the model is:

```text
Train Model

↓

Training Complete

↓

Apply GPTQ
```

No retraining is required.

GPTQ reduces the model size while trying to keep the output as close as possible to the original model.

---

## Why Use GPTQ?

GPTQ is useful because it:

- Reduces GPU memory usage
- Makes inference faster
- Keeps good accuracy
- Doesn't require retraining

It is commonly used when deploying models on GPUs.

---

# 12.2 AWQ

AWQ stands for:

**Activation-aware Weight Quantization**

Unlike GPTQ,

AWQ pays attention to **which weights are most important**.

Instead of treating every weight equally,

AWQ tries to preserve the weights that have the biggest impact on the model's output.

Think of it like packing for a trip.

You have limited suitcase space.

Instead of packing everything equally,

you carefully protect your most valuable items.

AWQ works in a similar way.

It tries to protect the most important weights.

---

## Why is AWQ Popular?

AWQ often provides:

- Better accuracy
- Lower memory usage
- Fast inference

This makes it popular for many modern open-source LLMs.

---

# 12.3 GPTQ vs AWQ

| GPTQ | AWQ |
|------|-----|
| Quantizes all weights | Gives more attention to important weights |
| Very popular | Newer approach |
| Good accuracy | Often better accuracy after quantization |

Both methods are excellent.

The choice depends on the model and deployment requirements.

---

# 12.4 What is GGUF?

GGUF is different it stands for **GPT-Generated Unified Format**.

It is **not a quantization algorithm**.

It is a **model file format**.

Think of it like this.

A document can be stored as:

- PDF
- DOCX
- TXT

The information is the same.

Only the file format changes.

Similarly,

an LLM can be stored in different formats.

GGUF is one of them.

---

# 12.5 Why Was GGUF Created?

GGUF was designed mainly for tools like:

- llama.cpp
- Ollama
- LM Studio

It makes it easier to:

- Load models
- Store model metadata
- Run quantized models efficiently

Especially on CPUs and personal computers.

---

# 12.6 Where is GGUF Used?

Suppose you want to run Llama on your laptop.

You'll often download a file like:

```text
llama-3-8b.Q4_K_M.gguf
```

Here:

```text
.gguf
```

is the file format.

The model inside may already be quantized.

---

# 12.7 Python Example

Loading a GPTQ model using Transformers.

```python
from transformers import AutoModelForCausalLM

model = AutoModelForCausalLM.from_pretrained(
    "TheBloke/Llama-2-7B-GPTQ"
)
```

The model has already been quantized.

You simply load and use it.

---

# 12.8 Which One Should You Choose?

| Use Case | Recommendation |
|----------|----------------|
| GPU deployment | GPTQ or AWQ |
| Local CPU inference | GGUF |
| Ollama | GGUF |
| llama.cpp | GGUF |

---

# Real-World Example

Imagine you want to send a large video.

You can:

- Compress it using ZIP
- Compress it using RAR

After compression,

you may save it as:

```text
video.zip
```

or

```text
video.rar
```

Compression and file format are related but not the same thing.

Similarly,

GPTQ and AWQ are **quantization methods**.

GGUF is a **file format** that often stores quantized models.

---

# Common Beginner Mistakes

### Mistake 1

Thinking GGUF is a quantization algorithm.

It isn't.

It is a model file format.

---

### Mistake 2

Thinking GPTQ and GGUF are competitors.

They are not.

GPTQ is a quantization method.

GGUF is a storage format.

---

### Mistake 3

Thinking every GGUF model uses the same quantization level.

Different GGUF files can use different quantization levels such as Q4, Q5, or Q8.

---

# Key Takeaways

- GPTQ is a Post-Training Quantization method.
- AWQ is a quantization method that preserves important weights more carefully.
- GGUF is a model file format, not a quantization algorithm.
- GPTQ and AWQ are commonly used for GPU inference.
- GGUF is widely used with llama.cpp, Ollama, and LM Studio.
